# hearth · decisions

Every design decision with its recommendation, reason, date and status. Q ids were open questions, decided the same day as the D rows; D10 and D11 were never assigned. Ids are permanent and never reused; a new row takes the next free D id. Status is decided, open (a question for the owner) or superseded by another id. This file is the only place a decision is recorded; other documents describe the result.

| D16 | Socket transport: Unix socket vs loopback TCP with a token | Unix socket via Network.framework/NIO, else loopback TCP with a per-launch token, Ollama-style | connect-swift's two HTTP clients both dial a host and port: the URLSession one because Foundation has no Unix-socket API, the NIO one because its bootstrap takes host and port only and would bring swift-nio, HTTP/2 and SSL into the app for nothing.
